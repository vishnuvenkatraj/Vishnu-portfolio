# Profile Photo Directory

This folder contains your official passport-size profile photograph for the portfolio.

## Current Photo:
- **File:** `profile-photo.jpg`
- **Recommended Aspect Ratio:** ~3.5:4.5 or 3:4 (standard passport dimensions)
- **Current Dimensions:** 803 x 1024 px

## How to Replace Your Photo in 3 Easy Steps:
1. Prepare your new passport-size photo.
2. Name it `profile-photo.jpg` (or `.png`).
3. Copy and replace the file here:
   `public/images/profile/profile-photo.jpg`

Your portfolio will automatically display the new photo without needing any code edits!
